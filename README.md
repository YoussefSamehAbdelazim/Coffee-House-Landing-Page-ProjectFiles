# ☕ Coffee House — Landing Page

A modern and responsive coffee shop landing page built with **HTML, CSS, and Vanilla JavaScript**.

Coffee House is a front-end website concept designed to present a coffee brand through a clean visual interface, responsive layouts, and structured content sections.

---

## ✨ Features

- ☕ Coffee shop themed landing page
- 📱 Fully responsive design
- 🎨 Modern and clean user interface
- 🧩 Structured landing page sections
- 🖥️ Responsive layouts for different screen sizes
- ⚡ Lightweight front-end implementation
- 🖼️ Image-based visual content
- 🔤 Custom web assets and icons
- 🌐 SEO-related website files

---

## 🛠️ Technologies

### Front-End

- HTML5
- CSS3
- Vanilla JavaScript

### Web & SEO

- Responsive Web Design
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`
- Open Graph image metadata

### Assets

- Images
- Custom icons
- Favicon files
- Web application icons
